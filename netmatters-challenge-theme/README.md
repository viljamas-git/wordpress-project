# Netmatters Challenge Theme

Custom theme scaffold for an engineering services business website with:

- Automation and control systems focus
- AI-enabled industrial solution positioning
- 3D printing and prototyping service framing
- Projects CPT for case-study style content

## Files to customize during implementation

- `front-page.php`: homepage section copy
- `archive-project.php`: project list intro and card layout
- `single-project.php`: case study narrative sections
- `template-parts/content-project-card.php`: card formatting

## Key custom fields expected on `project`

- `client_name`
- `project_url`
- `repo_url`
- `tech_stack`
- `features`
